# IronFit · Sistema de Gestão de Academia

Sistema web para gerenciar uma academia: alunos, planos, mensalidades, professores, fichas de treino e avaliações físicas, com um painel que resume a situação do mês.

Feito com Java 17, Spring Boot (API REST), H2 e front-end em HTML, CSS e JavaScript puro.

## Rodando

Com o JDK 17+ instalado, abra o projeto no IntelliJ e execute `AcademiaApplication`, ou use:

```
mvn spring-boot:run
```

Depois acesse http://localhost:8080. O banco é criado sozinho, já com dados de exemplo.
